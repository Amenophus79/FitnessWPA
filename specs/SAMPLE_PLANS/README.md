# Sample Plans

This folder contains importable JSON plans for parser, UI, and OpenAI output testing.

## Files

```text
MARATHON_2026_SAMPLE_PLAN.json
MARATHON_2026_TABATA_EXERCISE_CATALOG.json
```

## Marathon 2026 Sample

Target race date:

```text
2026-09-12
```

Training structure:

- Monday: Interval/Sprint
- Wednesday: Easy Run

- Tuesday: Tabata
- Sunday: Tabata

Included data:

## Marathon 2026 Tabata Exercise Catalog

`MARATHON_2026_TABATA_EXERCISE_CATALOG.json` contains reusable exercise definitions for the marathon-support Tabata movements:

- bodyweight squat
- glute bridge
- Bulgarian split squat
- side plank
- dead bug
- bird dog
- calf raise
- tibialis raise
- single-leg RDL

Import it through the Exercise Catalog panel before importing or generating plans that reference these exercise IDs.
